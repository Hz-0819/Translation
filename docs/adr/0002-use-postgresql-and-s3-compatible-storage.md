# ADR-0002：使用 PostgreSQL 与 S3 兼容对象存储

## 状态

Accepted

## 背景

账号、资料、错题本、套餐和用量之间存在强关系与事务要求，而 PDF、Word 和截图属于大体积二进制对象。

## 决策

PostgreSQL 保存关系数据、同步操作与对象元数据；S3 兼容存储保存文件内容。本地开发使用 MinIO，生产环境可替换为任意 S3 兼容服务。

## 结果

优点是强一致元数据、对象存储成本可控且厂商可替换。缺点是需要处理跨系统提交、孤立对象清理和签名地址过期。

## 备选方案

- 文件写入 PostgreSQL：备份和扩容成本高。
- 仅使用文档数据库：关系完整性和未来订阅交易更复杂。
