# ADR-0004：首版采用私有资料与邮箱密码认证

## 状态

Accepted

## 背景

跨设备同步和未来付费要求稳定账号身份，但首版不需要分享或协作权限。

## 决策

使用邮箱密码账号、Argon2id 密码哈希、短期内存访问令牌和 HttpOnly 刷新 Cookie。所有资料仅归单一用户所有；离线访客资料在登录后显式迁移。

## 结果

优点是厂商依赖低、权限模型简单、可支持容量套餐。缺点是需要自行维护密码重置、邮件验证、会话撤销和安全限流。

## 备选方案

- 验证码登录：依赖邮件或短信渠道。
- 第三方登录：厂商绑定较强。
- 首版协作 ACL：超出当前范围。
